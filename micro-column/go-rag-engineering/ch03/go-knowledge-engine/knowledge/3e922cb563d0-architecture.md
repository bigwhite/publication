# 系统架构

系统由用户服务、订单服务和支付服务组成。

用户服务负责用户请求入口，订单服务负责订单创建和状态管理，
支付服务负责支付请求处理。

服务之间通过 HTTP API 通信。每个服务独立部署，
并通过服务发现机制访问其他服务。

系统要求服务之间保持清晰的调用边界，
避免在请求链路中引入不必要的同步依赖。
