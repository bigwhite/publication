# 服务调用超时与重试规范

用户服务调用订单服务时，必须设置请求超时时间。

单次 HTTP 请求超时时间建议为 3 秒，
整个业务调用链路的总超时时间不得超过 5 秒。

重试必须设置最大次数，默认最多重试 2 次。
对于非幂等请求，不得在没有幂等保护的情况下自动重试。

当下游服务持续超时，应结合熔断机制限制请求量，
避免重试放大故障。
