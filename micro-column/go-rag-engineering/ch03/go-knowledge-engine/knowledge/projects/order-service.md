# 订单服务项目概览

## 1. 项目职责

订单服务负责订单相关业务能力，包括：

- 创建订单。
- 查询订单。
- 更新订单状态。
- 管理订单业务数据。

## 2. 上游依赖

用户服务是订单服务的重要调用方。

用户服务通过 HTTP 接口调用订单服务，完成用户侧的订单业务流程。

## 3. 关键工程约束

订单服务需要关注：

- HTTP 请求超时。
- 调用链路总超时。
- 重试请求的负载影响。
- 非幂等请求的重复执行风险。
- 连接池资源使用。
- 熔断保护。

## 4. 已知故障

2026 年 3 月，用户服务调用订单服务时曾出现间歇性超时，并最终导致订单服务连接池耗尽。

故障与调用链路超时控制不足、重试请求放大负载有关。

详细分析见：

[订单服务超时故障复盘](../incidents/order-timeout.md)。
